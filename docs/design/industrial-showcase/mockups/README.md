## A：搜索与询价优先

电脑采用蓝白目录与大搜索框，手机改为搜索优先、双列分类、单列产品行和底部询价入口。关键页展示筛选抽屉打开状态；背景列表显示上一次结果，抽屉展示待应用条件的匹配数，点击后才更新列表。示例型号与参数仅供界面演示。

## C：工艺、样件与需求沟通

电脑采用黑橙工艺主视觉、三列样件及交付流程。手机将加工照片主体下移，给标题保留暗色阅读区域；样件改为纵向内容，底部保留加工需求入口。表单使用浅色背景，展示工艺、材料、数量、交期与补充说明，注明只整理、不发送。

手机首页生成稿中，说明与次要按钮区域仍与照片暗部相接；实现时应按原方案将文案与照片分为独立区域，确保不同裁切下的对比度稳定。静态效果稿不代表键盘弹出、筛选关闭、滚动或摘要生成已经可用。

## 素材与生成记录

本轮使用内置 Image Gen。A 电脑稿参考了调研阶段已查看的 Accu 截图中的搜索层级和产品摄影方式；C 电脑稿参考了 PrecisionCore 截图的工艺摄影氛围。两套均使用原创版式与示例品牌。后续手机稿分别以本套电脑/手机稿作为视觉参考，保持品牌一致。

图中的产品、样件和工艺画面为生成式概念素材，不代表真实产品型号、真实工厂或已经验证的加工能力。后续生产素材按 [素材计划](../asset-plan.md) 独立准备、核验并记录，不把整张效果稿作为网页背景。

完整提示词保存在 [prompts.md](prompts.md)。图片原始文件仍保留在图像工具生成目录，本目录保存工程内交付副本。
