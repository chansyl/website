目前候选能够支持工艺、仓储和部分品类场景，**尚不是四套网站的完整图片包**。尤其 D 的统一产品图需要单独制作。

| 缺口 | 首选办法 | 无现成授权时的替代 |
| --- | --- | --- |
| A 的多品类白底产品图 | 客户/供应商授权图库，或自行拍摄 | 原创通用品类示意，明确不对应真实销售型号 |
| B 的气动/流体组件及连贯应用图 | 经许可的厂商产品包 + 精选场景图库 | 原创组件示意与简化应用流程图，不提供虚构工程结论 |
| C 横幅加工图、样件、检验照片 | 许可清楚的工业摄影，真实客户补拍 | 演示样件原创渲染；生成图只用于氛围/概念展示，不充当工艺、尺寸或精度证据 |
| D 外壳系列及各角度图 | 自行制作统一基础外壳模型并渲染，或客户授权实拍 | 缩小为 3 个系列、每系列 2 款；全部标为示例产品，规格仅为界面演示 |

## 4. 设计与资源生产约定

- 原始图与许可记录保留在设计素材目录，网页仅使用优化版本；不将图库原图直接外链作为线上资源。
- 电脑首图目标横幅 16:9 或更宽，手机首图单独选择 4:5/3:4；品类/产品图采用 1:1，工艺与场景内容图采用 4:3。裁切前检查主体是否完整。
- 同一套网站统一色温、背景与产品投影，不把手机强行裁剪后的残缺机器作为主视觉；图片中不烧录标题或按钮文字。
- 产品照片必须对应实际展示内容；图片是品类示意时，在邻近位置明示。示例参数不用于采购或生产，不填虚构库存、成交量、认证与交付承诺。
- 每张最终采用的图登记：文件名、作者、原始页面、下载日期、许可地址/证据、授权范围、是否修改、所用页面、是否仅演示。CC 图片保留适当署名页；正式客户替换后更新台账。
- 获取原图后再生成 WebP/AVIF 与所需尺寸，校验手机加载预算。视频不是首期必要素材。

## 5. 下一步素材工作

方案确认后，先为 A+C 各整理一张素材板和完整缺口表，选择并检查原图、准备示例产品/样件、完成双端裁切。素材板与设计稿一并确认后，再进入网页实现。此阶段可明确看到哪些是真实摄影、哪些是原创示意，以及正式客户交付时需要替换什么。
